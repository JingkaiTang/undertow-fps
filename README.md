# 逆潮 UNDERTOW

一款单文件浏览器 FPS。暴雨中的九号海岸泵站即将被潮水淹没。击落两波共五架失控巡检机，再到泵房背墙的控制柜重启泄洪闸。

**[在线试玩](https://jingkaitang.github.io/undertow-fps/)** · 也可以下载 `index.html`，用桌面浏览器打开，离线游玩。

**操作**　WASD 移动，鼠标转向，左键射击，右键瞄准，R 换匣，E 操作控制柜，Esc 暂停。

这是一次受《Saltline》启发的复现实验。在 Codex 中使用 GPT-6 Astra（Ultra 推理强度）和 `/goal`，从提交任务到交付用时 26 分 59 秒。场景、材质和声音均由代码生成，Three.js 也内嵌在 HTML 中。[三款作品的实机对照](comparison.jpg) · [复现实验讨论](https://github.com/wquguru/fable52-fps-repro/issues/1)
